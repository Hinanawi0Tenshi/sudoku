## 数独项目上线（首次部署）
- 线上地址：https://sudoku-studio.app.workbuddy.host/ （App 名「数独工作台」，已 verified）
- 部署方式：静态托管（`language: static`），目录 `D:/Downloads/数独`，`entryHtml` 无需指定（单应用目录，自动识别 index.html）
- 部署前核查结论（这些性质决定了它适合静态托管，后续改动不要破坏）：
  - 完全自包含：Tesseract 的 worker / 4 个 core / eng.traineddata.gz 全在 `js/vendor/`，**无任何 CDN 外链**
  - `js/ui/18-ocr.js:190` `VENDOR = 'js/vendor/'` 是**相对路径**，所以站点必须部署在根路径下（子目录会 404）
  - 没有裸 `.wasm`：4 个 core 都是内嵌 wasm 的 `.wasm.js`，避开 wasm MIME 类型坑
  - 无外部数据库 / 后端依赖，全部数据存 localStorage
- 体积：总计 32M，其中 `js/vendor` 20M（上传大头），`.git` 11M 已被部署工具排除
- 线上校验：index.html / css/app.css / js/core/04-generator.js / js/ui/18-ocr.js 与本地 md5 完全一致；
  20M OCR 资源（worker.min.js、core-simd-lstm.wasm.js、eng.traineddata.gz）均 200

## 环境备忘（踩坑）
- `tests/browser-test.js` 支持 `node tests/browser-test.js <URL>` 换目标地址，但**在沙箱内跑不起来**：
  spawn headless Edge 会让整个命令被 SIGTERM 直接杀掉，连 echo 都不执行。想验证线上页面不能用这条路。
- 替代验证手段：curl 比对 md5 + 检查关键资源 HTTP 状态码。
